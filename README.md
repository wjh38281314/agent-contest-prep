## 每周怎么提交（网页路线，三步）

1. 打开仓库网页，点 `Add file` → `Upload files`
2. 把这周改过 / 新增的文件拖进去（同名文件会覆盖）
3. 在 `Commit changes` 输入框写一句这周做了什么，例如 `week02: 加了按截止日期排序`，点绿色按钮

网页上每改一次文件，GitHub 就自动记一条提交 —— 这就是老师要的「每周提交记录」。

> 以后如果装了 Git，也可以改用命令行三步：`git add .` → `git commit -m "说明"` → `git push`。两种方式都会留下提交记录，挑顺手的用。

## 是不是每次都要开网页打开仓库？

**按现在的网页路线：是。** 每周改完文件，到网页上传一次、写一句说明，就有新记录。

如果以后装了 Git，就可以只在本地文件夹改，用 `commit` + `push` 两条命令同步，网页只在建仓库、加协作者、查看提交记录时打开。

- 本地文件夹 = 你的作业本
- GitHub 网页 = 交上去之后的公示栏
- 上传 / `push` = 「交作业」这个动作
