# 智能体备赛练习仓

面向「第十八届蓝桥杯 · 人工智能赛 · 智能体开发科目」的过程性练习仓库，用于持续沉淀每周可运行的最小成果与配套笔记。

- 创建时间：2026-11-17
- 主要语言：Python（仅标准库）

## 项目定位

本仓库同时服务两项目标：

1. **课程要求**：以公开仓库形式维护一个 agent 项目，并保留连续的每周提交记录，作为过程性材料。
2. **竞赛准备**：按《智能体竞赛备战资源包》第六节「6 周起手包」的节奏，逐步完成从手写 ReAct 循环到可评测智能体的练习。

设计原则是每周交付一个**可运行的小成果**与一篇短笔记，练习场景优先选择熟悉的实际需求。示例实现不依赖第三方框架、API 密钥或网络服务，便于在低配置环境中复现。

## 环境要求与运行

- Python 3.8 及以上，仅使用标准库（`datetime`、`pathlib`）
- 无需安装依赖、无需配置密钥、无需联网

在项目根目录执行：

```bash
python week-01/react_loop.py
```

Windows 环境亦可使用 `py week-01/react_loop.py`。

程序从 `tasks.txt` 中检索「蓝桥杯报名」对应的日期，经由两个本地工具（`查安排`、`算天数`）完成两轮推理，输出距离报名截止的天数。2026-11-21 的运行示例：

```text
问题： 蓝桥杯报名截止还有几天？

第 1 轮
  Thought     ： 要回答这个问题，得先知道报名截止是哪天
  Action      ：查安排('蓝桥杯报名')
  Observation ： 2026-12-18,蓝桥杯报名截止（14:00）

第 2 轮
  Thought     ： 拿到日期了，接下来算还剩几天
  Action      ：算天数('2026-12-18')
  Observation ： 27

  Thought     ：信息够了，可以回答了

  Answer      ： 蓝桥杯报名截止是 2026-12-18，还有 27 天。
```

> 输出中的天数随实际运行日期变化。

该示例不接入大语言模型，计划序列暂时固定，用于展示智能体的最小控制流：判断所缺信息 → 选择工具 → 读取结果 → 决定下一步 → 给出回答。后续迭代将逐步引入动态编排与可复现评测。

## 提交规范

- 每周至少一次提交，提交信息说明本周改动，例如 `week02: 增加按截止日期排序`。
- 每次提交应包含可运行的代码或可复现的记录，避免无实质内容的改动。
- 提交历史同时作为课程过程性材料与竞赛迭代记录；需求拆解、失败案例与评测结果在对应笔记中留存。
